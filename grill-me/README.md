# grill-me

`grill-me` is a Codex skill for stress-testing plans, designs, and implementation ideas through focused questioning.

Use it when you want Codex to:

- Interview you one question at a time.
- Walk through the decision tree behind a plan.
- Resolve dependencies between design choices.
- Recommend an answer for each question.
- Inspect the codebase directly when a question can be answered from local context.

The skill is intentionally direct: it keeps pressure on unclear assumptions until the plan is concrete enough to act on.
